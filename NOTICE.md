# Project identity and upstream attribution

xhttp-box is an independently maintained, unofficial derivative of
[SagerNet/sing-box](https://github.com/SagerNet/sing-box).

The `sing-box` name appears in this repository only where needed to identify
the upstream source, preserve copyright and attribution notices, maintain
source-level compatibility, or document interoperability. xhttp-box is not
affiliated with, endorsed by, sponsored by, or maintained by SagerNet,
nekohasekai, or the original sing-box maintainers.

Distributed executables, packages, services, container images, and release
archives produced by this repository use the `xhttp-box` name. Issues related
to xhttp-box should be reported to the
[xhttp-box issue tracker](https://github.com/flyzstu/xhttp-box/issues), not to
the upstream project.

The original copyright and license notices are preserved in
[LICENSE](LICENSE). Source-level references such as the Go module and import
paths remain unchanged to support upstream synchronization and are not claims
of affiliation.
